# 1枚目の帳票

使用する既存の1枚目PDFは `assessment_form.pdf` です。ユーザーが配置した元ファイルは変更・上書きしません。
元ファイルを再描画せず、氏名overlayの背景として使用します。
配置完了後の元ファイルは18,358バイト、1ページ、595.44 × 842.4 pt（A4縦相当）です。
SHA-256: `ffbc062f6b62263c774e5e576e3c698049d449ea32f9fbc40398ececb28f8fa8`
`app/pdf/coordinates.py` の氏名座標は、この元帳票を画像化して確認した位置です。
用紙左上からx=38.5 mm、y=36.0 mm、幅38.0 mm、高さ4.5 mm。標準12 pt、最小8 ptです。
